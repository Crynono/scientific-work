# Численное решение уравнения Кортевега — де Фриза (KdV)

## Описание проекта

Данный проект реализует численное решение **уравнения Кортевега — де Фриза** с периодическими граничными условиями. Программа моделирует распространение **солитонов** — уединённых волн, сохраняющих свою форму при движении.

Уравнение KdV является фундаментальным уравнением математической физики и описывает нелинейные волны малой амплитуды в различных средах (мелкая вода, плазма, оптические волокна).

## Математическая постановка

### Уравнение
$$u_t - u_{xxx} + u \cdot u_x = 0$$

где:
- $u(x,t)$ — искомая функция
- $u_t$ — производная по времени
- $u_{xxx}$ — третья производная по пространству (дисперсия)
- $u \cdot u_x$ — нелинейное слагаемое

### Граничные условия
Периодические: $u(0,t) = u(L,t)$

### Начальное условие
Солитон:
$$u(x,0) = \frac{c}{2} \cdot \text{sech}^2\left(\frac{\sqrt{c}}{2}(x - x_0)\right)$$

где $c$ — скорость солитона, $x_0$ — начальная позиция.

## Численный метод

### Разностная схема
Используется **неявная разностная схема** первого порядка по времени:

$$\frac{u_i^{j+1} - u_i^j}{\tau} = \frac{u_{i+1}^{j+1} - 3u_i^{j+1} + 3u_{i-1}^{j+1} - u_{i-2}^{j+1}}{h^3} - \frac{(u_{i+1}^{j+1})^2 - (u_{i-1}^{j+1})^2}{h}$$

### Метод Ньютона
Для решения нелинейной системы применяется **метод Ньютона-Рафсона**:
1. Вычисляется невязка $F(u^{j+1})$
2. Строится матрица Якобиана $J = \frac{\partial F}{\partial u}$
3. Решается СЛАУ: $J \cdot \Delta u = -F$
4. Обновление: $u^{j+1} = u^{j+1} + \Delta u$

### Структура матрицы Якобиана
Матрица имеет **4-диагональную структуру** с периодическими угловыми элементами:
- Диагональ $-2$: $\kappa = \tau/h^3$
- Диагональ $-1$: $-3\kappa + \frac{12\tau}{h} u_{i-1}$
- Главная диагональ: $1 + 3\kappa - \frac{9\tau}{h} u_i$
- Диагональ $+1$: $-\kappa - \frac{\tau}{h}(2u_{i+1} + u_i)$
